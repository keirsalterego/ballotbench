Check it yourself, offline

This portal's key is {{ key.key_id }}; the full public key is at /.well-known/ballotbench-signing-key. The signature is Ed25519 over the record's canonical JSON: keys sorted, no spaces, UTF-8. With Python and the cryptography package:

import base64, json
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PublicKey

key = Ed25519PublicKey.from_public_bytes(base64.urlsafe_b64decode("{{ key.public_key }}="))
doc = json.load(open("record.json"))
body = json.dumps(doc["record"], sort_keys=True, separators=(",", ":"), ensure_ascii=False).encode()
key.verify(base64.urlsafe_b64decode(doc["signature"] + "=="), body)   # raises if it isn't genuine
